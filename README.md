🐾 AI Pet Classifier
A simple deep learning web app that classifies images as Cat 🐱 or Dog 🐶 using TensorFlow and Streamlit.

Built with:
TensorFlow / Keras
Streamlit
Plotly
Python

  Features:
Upload pet images
Real-time prediction
Confidence score
Interactive analytics dashboard
Prediction history
Clean dark UI

Model Information:
The model is a CNN (Convolutional Neural Network) trained on a Cats vs Dogs dataset.
Architecture
Conv2D
MaxPooling
Dense Layers
Sigmoid Output
Input Size: 150 × 150 RGB image
